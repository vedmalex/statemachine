    Optionalfinal

    final?: boolean

    Marks this atomic state as the SCXML/UML <final> pseudo-substate of its region. When every region of a composite has its active atomic leaf marked final, that composite is "done": the engine raises the done.state.<id> event and StateMachine.isDone returns true. Only meaningful on a leaf state (a state without regions); set on a composite it is ignored at runtime and flagged by the config validator.
